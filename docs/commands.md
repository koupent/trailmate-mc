# チャットコマンド

次の公式ワードで Trailmate MC に指示できます。雑談で呼びかけるときは `@Trailmate 今どう？` のように、ワールド内のボット名を使います。

| ワード | 動作 | 返答例 |
|---|---|---|
| `待機` | その場で待機 | うん、ここでちょこんと待ってるね！ |
| `追従` | 発言者をオーナーにして追従 | よーし、ついてくね！ |
| `全回収` | インベントリをすべて発言者へ渡す | はいっ、持ち物を全部渡すね！ |
| `拠点` | `/spawnpoint` で復活地点を設定（権限が必要な場合あり） | よし、ここを拠点にしたよ！ |

文の一部に含まれていれば反応します（例: `ちょっと待機して`）。

英語エイリアスはありません。多言語コマンドが必要なら `dialogueParse` のキーワード定義と locale を拡張してください。

## ダッシュボードから使う

ダッシュボードの「プレイ」ページの「モードとコマンド」に、ここにあるワードが一覧で出ます。

- **実行**: ロック済みのオーナーがそのワードをチャットしたのと同じ動きをします（返事もゲーム内チャットに出ます）。
- **コピー**: ワードをクリップボードへコピーします。マイクラのチャットにそのまま貼れます。

一覧は `dialogueParse.js` の定義から作られるので、ワードを増やせばダッシュボードにも自動で出ます。
