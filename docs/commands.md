# チャットコマンド

Trailmate は雑談には返事しません。次の公式ワードだけ反応します。

| ワード | 動作 | 返答例 |
|---|---|---|
| `待機` | その場で待機 | わかった、ここで待つね |
| `追従` | 発言者をオーナーにして追従 | ついていくね |
| `全回収` | インベントリをすべて発言者へ渡す | 全部渡すね |
| `拠点` | `/spawnpoint` で復活地点を設定（権限が必要な場合あり） | ここを拠点にしたよ |

文の一部に含まれていれば反応します（例: `ちょっと待機して`）。

英語エイリアスはありません。多言語コマンドが必要なら `dialogueParse` のキーワード定義と locale を拡張してください。
