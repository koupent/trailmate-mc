サーバー住所と（必要なら）Microsoft ログインを完了すると、プレイ画面に切り替わります。

    設定

    接続先・アカウントと、相棒が手元に残すアイテムを設定します。

    相棒が手元に残すもの

    チェストを置いて返してもらうとき、相棒が自分用に残すアイテムです。 カテゴリごとの合計と、アイテムごとの上限の両方を指定できます。 保存すると、デスポーンせずに次の返却から反映されます。

    読み込み中…

    サーバー設定

    ワールド内の名前

    Microsoft アカウント登録後に表示されます

    オンラインでは、ログインした Minecraft プロフィール名がそのまま使われます。 この画面の入力では変えられません（変更は Minecraft / Microsoft 側の名前変更になります）。

    サーバー住所がプレースホルダのままです。保存してください。

    Microsoft ログイン

    オンラインサーバー用。ボットとして使う Microsoft アカウントでログインします。
