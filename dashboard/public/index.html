Trailmate MC

start.bat / stop.bat は Docker 用。この画面はワールドへの出し入れと設定です。

初回セットアップ

サーバー住所と（必要なら）Microsoft ログインを完了すると、運用画面に切り替わります。

アップデート

公開中の最新版を確認し、必要なら取り込みます。

更新中はボットが再起動します。ホスト側ファイル（docker-compose.yml など）の変更がある場合は ZIP の再展開が必要です。
